# Component specs

Tokens: `replica/design/tokens.json` -> `app/tokens.css` (generated by
`npm run tokens`) -> Tailwind theme (`bg-surface`, `text-muted`, `rounded-md`).
Icons: Lucide (ISC licence). Font: system stack with Inter if installed (the
original's typeface is proprietary and is not used). All copy written fresh.
Primitives live in `components/ui/*` and render together at `/design`.

Every interactive element: real HTML element, visible 2px focus ring in
`accent` with 2px offset, minimum 48px tap target on rider and driver screens.

```
Button
  variants  primary (bg accent, text on-accent), secondary (bg surface, text text),
            ghost (transparent, text text), danger (bg danger, text on-danger)
  sizes     md 48px (default on phone screens), sm 36px (admin tables), lg 56px (Request, Go)
  states    default, hover (opacity .9), active (scale .98), focus-visible ring,
            disabled (opacity .45, not-allowed), loading (spinner + label kept for screen readers, aria-busy)
  tokens    radius md (pill for the round Go button), type base/600
  a11y      <button>, type set, loading keeps accessible name
  used on   all

Input / AddressField
  variants  text, tel, address (leading dot: pickup green, drop-off square)
  states    empty, focused, filled, error (border danger + message, aria-invalid, aria-describedby), disabled
  tokens    bg surface, border transparent -> border-input on focus, radius md, 48px
  a11y      <label> always (visually hidden allowed on address fields), autocomplete attrs
  used on   S01, S03, S06, S16, S20, S27

OtpInput
  one <input inputmode="numeric" autocomplete="one-time-code" maxlength=6>, large letter-spaced
  states    empty, error ("That code didn't match"), expired, resend countdown
  used on   S02

MapView
  variants  provider tiles (Mapbox/Leaflet when MAPBOX_TOKEN set) or schematic fallback (SVG grid,
            no network) - same props: center, markers[], route[], fitTo
  markers   you (pulsing dot), pickup (green dot), drop-off (black square), stop (numbered), car (rotated by heading)
  states    loading, no location (centre on city), following car
  a11y      map is aria-hidden decoration; every fact on it (ETA, address, driver) is also text in the sheet
  used on   S05-S12, S21-S24, share page

BottomSheet
  fixed to bottom, max-width layout.app-max, radius lg on top corners, shadow sheet, scrolls inside
  states    peek, expanded (content-driven); no drag gesture in MVP (scroll instead)
  used on   S05-S13, S19, S21-S25

ProductCard (ride option)
  radio-style <button role="radio" aria-checked>, icon, name, seats, ETA to pickup, price
  states    default, selected (2px border accent, bg accent-soft), unavailable (muted, "No cars nearby"), busy (price-up note in warning)
  used on   S07

DriverCard
  avatar initials, first name, rating (star + 1 decimal), car colour + make + model, plate in a mono pill
  used on   S10, S12, share page

OfferCard (driver)
  pickup distance + minutes, drop-off area, estimated earnings, countdown ring (15 s) with seconds as text,
  Accept (primary lg) and Decline (ghost)
  states    live, expiring (<5 s, warning), expired, taken ("Another driver got this one")
  a11y      aria-live="assertive" announcement when an offer appears; vibration where allowed
  used on   S22

ConfirmSlider -> replaced by a hold-to-confirm Button (press and hold 600 ms) for Start/End trip:
  same intent (no accidental taps), keyboard: Enter/Space held, or double-activate fallback
  used on   S24

StarRating
  radiogroup of 5 <button role="radio">, arrow keys move, labels "1 star".."5 stars"
  used on   S13, S25

TipChips
  preset buttons (3 amounts derived from fare) + custom amount input, "No tip"
  used on   S13

ChatThread
  bubbles (mine: bg accent/on-accent, theirs: bg surface), composer with 500-char limit, quick replies
  states    empty, sending, failed (retry), unread count badge on the chat button
  used on   S11

Modal / ConfirmSheet
  <dialog> with focus trap, Esc closes, title + body + two buttons
  used on   S19 cancel, refunds in admin

Banner
  variants  info (surface), warning (warning-soft/warning), danger (danger text), success
  role=status (info/success) or role=alert (danger)
  used on   S07 busy pricing, S09 no drivers, S21 background-location warning

ListRow
  leading icon, title, subtitle, trailing value/chevron; whole row is a link or button
  used on   S15-S18, S26, menus

Countdown / WaitTimer
  mm:ss text + optional ring; announces at 0 via aria-live polite
  used on   S09, S10, S22, S23

FileUpload
  <input type=file accept> styled as a tile, shows filename/size, errors for >5 MB or wrong type
  states    empty, uploading, uploaded (pending review), rejected
  used on   S20

DataTable (admin)
  <table> with sticky header, sm buttons, empty row message
  used on   S28

Skeleton
  surface-2 blocks with a slow pulse (disabled under prefers-reduced-motion)
  used on   loading states everywhere
```

Layout: rider and driver screens are a full-height map with a bottom sheet,
content capped at 480px wide and centred on desktop. Admin is a 1200px
max-width page with a top nav. Breakpoints: 390 (phone), 768, 1440.
